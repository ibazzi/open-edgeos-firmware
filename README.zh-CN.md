# Open EdgeOS Firmware

[English](README.md) | 简体中文

面向 Ubiquiti EdgeRouter 设备的社区固件开发项目，当前重点为 **EdgeRouter 4（ER-4）**。

本仓库用于固件发布、版本说明、问题反馈和项目讨论。这是一个独立项目，与 Ubiquiti 无隶属关系，也未获得其官方背书。

> **当前状态：实验性。** 部分功能已在 ER-4 实机完成限定场景验证，但硬件、兼容性、恢复、性能及稳定性的完整验收尚未完成。单项功能测试通过不代表固件已具备生产环境使用条件。

## 项目概况

本项目旨在为现有 EdgeRouter 设备引入更新的 Linux 底层，同时保留用户熟悉的 EdgeOS CLI、配置流程、Web 界面及服务行为，并在后续持续引入更多新功能与新特性，延续现有设备的使用价值。

**本项目完全由 AI 驱动。** 从分析、实现、兼容适配到测试与文档编写，项目开发流程均由 AI 驱动推进。

当前实现由以下部分组成：

- 基于 OpenWrt 的 Octeon 内核与板级适配，当前使用 Linux 6.12.112。
- Debian Buster MIPS 大端 O32 用户空间。
- Vyatta/EdgeOS 管理层，以及面向新内核和运行环境的兼容适配。

兼容现有 EdgeOS 行为是项目目标，目前尚不能保证完整功能对等，也不能保证所有旧配置均可自动迁移。内核更新本身也不代表所有用户空间组件均已更新，或固件已达到某个安全维护基线。

## 支持设备

“当前目标”表示正在开发和测试的机型，不代表所有功能均已通过验收。

| 设备 | 状态 |
| --- | --- |
| **EdgeRouter 4（ER-4）** | 当前开发与实机测试目标，实验性支持 |
| EdgeRouter 6P（ER-6P）、EdgeRouter 12（ER-12）、EdgeRouter 12P（ER-12P） | 尚未验证，板级、端口及启动兼容性待确认 |
| 其他 EdgeRouter 机型 | 目前无受支持的发布版本 |

共享平台或固件系列名称（包括 `e300`）不代表不同机型可以通刷。只有版本说明明确列出你的具体机型时，才应使用对应镜像。

## 固件下载与安装

准备工作、校验方法、Web/CLI 安装步骤、首次启动检查及恢复注意事项见[固件刷机说明](INSTALL.zh-CN.md)。

公开发布的固件放在本仓库的 **GitHub Releases** 中。设备支持、已知问题和安装方法以对应版本的说明为准。本 README 不表示已有稳定版本，也不表示固件文件已可下载。

每次发布应提供：

- 明确支持的机型、版本号、构建日期及 debug/release 模式。
- 固件文件及 SHA-256 校验值。
- 更新内容、已验证功能、已知问题及未验证范围。
- 要求的起始固件与 Bootloader 版本、配置兼容性说明和安装步骤。
- 备份要求、恢复前提，以及升级/回退已验证的范围。
- 组件与源码来源，以及适用的许可声明。

安装前请备份原始配置，并将备份保存在路由器之外。确认镜像机型和校验值，并按对应版本说明准备恢复入口。保留 `config.boot` 不代表所有配置项都能成功迁移，也不要假定存在自动回退机制。

首次安装前，须先在官方 EdgeOS 环境中将 Bootloader 更新至适用于具体机型的官方最新版本。检查方法及官方更新入口见[Bootloader 前置要求](INSTALL.zh-CN.md#bootloader-前置要求)。本项目的系统镜像安装流程不会代为完成该更新。

当前开发固件通过跳过自动 Bootloader 写入、SPI 只读保护、保留原存储布局、早期启动检查及 RAM 环境有序关机等措施降低启动和存储风险。具体保护范围及各版本的核验要求见[启动与存储保护措施](INSTALL.zh-CN.md#启动与存储保护措施)。这些措施不构成必然可恢复或自动回退的保证。

## 问题反馈与讨论

可复现的缺陷、设备兼容性反馈和功能建议请提交到 **GitHub Issues**。提交前先搜索已有问题，每个 Issue 尽量只讨论一个问题。欢迎使用中文或英文反馈。

一般使用问题和想法可在 **GitHub Discussions** 讨论（如已启用）；未启用时可提交 Issue，并注明是问题咨询或功能建议。功能建议不代表项目已承诺实现或交付时间。

**上游代码缺陷：** 经确认属于上游代码的缺陷，需由对应上游项目修复，本项目随后同步上游修复并更新。具体更新时间取决于上游修复的发布进度及兼容性验证结果。反馈此类问题时，如已有上游 Issue 或修复链接，请一并提供，便于跟踪处理进展。

报告缺陷时，请提供以下信息：

```text
设备型号及硬件版本：
固件版本 / 发布标签，以及 debug 或 release 模式：
原固件版本及安装/升级方式：
相关拓扑、接口与配置（已脱敏）：
复现步骤：
预期行为：
实际行为：
发生频率及影响：
相关日志 / 截图：
恢复步骤或临时解决方法（如有）：
```

发布前请删除密码、私钥、令牌、VPN 密钥及可识别个人或网络身份的信息。优先提供最小相关配置和日志片段，不要上传未经脱敏的完整备份。反馈吞吐或加速问题时，还请说明流量方向、包长、已启用功能、对端环境及 CPU 占用。

疑似安全漏洞请优先使用 GitHub 的私密 **Report a vulnerability** 入口（如可用）；否则先请求私密反馈渠道，不要公开敏感细节。
